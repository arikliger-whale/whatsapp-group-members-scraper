# WhatsApp Group Members Scraper

Script to export WhatsApp group members into a CSV file. It runs in the browser — no extension and no proxy. Open the [WhatsApp Web client](https://web.whatsapp.com/), copy-paste the script into your Chrome console, and click **Export**. The script reads WhatsApp Web's own IndexedDB (`model-storage`) and downloads every member in one shot. It does **not** scrape the DOM member modal, so you do not need to open "View all" or scroll the list.

![WhatsApp Group Members Scraper](statics/screen_script.png)

 Read our step-by-step [guide to scrape WhatsApp group members](https://www.datablist.com/how-to/scrape-whatsapp-group-members-free)

## How to run the WhatsApp Users Extractor script

 1. Open [WhatsApp Web](https://web.whatsapp.com) on Chrome and open the group chat (Hebrew UI is fine). You do **not** need to open group info or the members modal.
 1. Open Chrome Developer Console
 1. Copy-paste the following code into the console. A small widget appears.
 1. Click **Export** (or wait — the script auto-runs once). It reads IndexedDB and downloads a UTF-8 BOM CSV of **all** members. No scrolling.
 1. Some members only have a LID (`@lid`), not a phone — WhatsApp no longer gives the number unless they are a saved contact or have shared it. Those rows still export with name + id.


## Language support

- Works with WhatsApp Web in Hebrew and other languages, and with non-Latin names.
- Group matching uses the visible chat title (including Hebrew). Info modal is not required.
- CSV is UTF-8 with BOM (Excel-safe).
- This is an IndexedDB `model-storage` export, not DOM scraping.

## Exported Fields

- **Phone Number**: Digits from a `@c.us` id, or from the contact record when a `@lid` can be resolved. Empty when WhatsApp only stored a LID.
- **Name**: Contact name (or pushname / verified / short name).
- **Pushname**: WhatsApp push name, when stored.
- **Source**: Name of the WhatsApp group
- **Id**: WhatsApp id (`123@c.us` or `456@lid`)

## FAQ

- **How to remove the widget?**
    - Just reload your WhatsApp page. Any javascript code added in Chrome Developer Console will be removed.
- **How many users can be extracted?**
    - All members WhatsApp Web has stored for that group in IndexedDB. There is no scroll / virtualization limit.
- **Why is the phone number empty?**
    - WhatsApp often stores a LID (`@lid`) instead of a phone. The number is only available if the person is a saved contact or has shared it. The row is still exported with Name + Id.
- **Can I extract users from different groups**
    - Yes. Open another group and click Export again. The CSV Source column is the group name.
- **What is the Reset button?**
    - It clears the widget status line only. Export reads IndexedDB again each time.
- **Is it free?**
    - The script is free and open-source. You can also clean and parse the data with a free account on [Datablist](https://www.datablist.com).
